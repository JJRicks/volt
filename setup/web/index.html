Enable USB debugging & connection helpStart here if USB debugging isn’t on yet.
  1. On your phone, open Settings → About phone. Tap Build number seven times. On Samsung, open Software information first.
  2. In Developer options, turn on USB debugging. Connect the cable and unlock your phone.
  3. Close other scooter apps, Android Studio, scrcpy, and other USB setup tabs. If ADB is installed on this computer, run adb kill-server in a terminal: its background server keeps the phone busy after adb devices finishes.

Only the main personal Android user is supported; work profiles and secondary users are not supported.

Browser capture is still being validated. If the browser can’t connect or capture doesn’t finish, complete any cleanup here first, then use the computer ADB helper in the setup guide.

This page cannot connect to the phone it’s running on. On Linux, the browser needs Android udev rules (Ubuntu or Debian: android-sdk-platform-tools-common); Snap or Flatpak browsers may not see USB phones. Windows may need your phone’s USB driver; a work-managed phone may block debugging.

What happens to my data?

Only fresh NAVEE authentication messages are read by this helper. NAVEE itself may log more while logging is enabled. Your NAVEE password is never read, and the capture is never uploaded.
