RECOVERY GUIDE

Get your phone back to normal.

A missing USB reply is not proof that cleanup failed—or that it succeeded. The helper checks before offering a setup file.

Independent community project. Volt is not affiliated with, sponsored by, or endorsed by NAVEE or its app vendor.

Try the built-in recovery first.

  1. Leave this browser profile’s site data intact. The recovery record contains the phone serial, random session token, and original NAVEE log setting. It contains no scooter owner identity.
  2. Wait two minutes for the phone’s cleanup timer to attempt restoration. A reboot or operating system process kill can interrupt it.
  3. Reconnect the same phone with a data cable. Unlock it, then return to the setup page and choose Connect phone and recover.
  4. Approve the new USB debugging prompt if asked. A page reload discards the old temporary browser key.

If cleanup cannot be verified

On your phone, open Settings → Apps → NAVEE → Force stop. This closes the app that may have cached temporary verbose logging. It does not by itself restore the log property.

On the setup page, choose Download recovery instructions. The file includes the exact pre-capture setting and commands for a trusted computer running Android Platform-Tools. The commands are for macOS/Linux shells; a person helping with Windows should use the listed values with proper Windows quoting.

Do not delete the phone’s capture-lock directory, clear the browser’s site data, or start another helper just to bypass the warning. A still-running cleanup timer could otherwise interfere with a new session.

If the downloaded instructions report an incomplete preparation or the lock belongs to a different helper, ask the person who supplied Volt to help verify it. Share the recovery instructions if useful; never share a captured owner-setup JSON.
