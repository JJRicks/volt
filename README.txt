VOLT — Your scooter. Your connection.

An independent Android companion for NAVEE scooters. Volt is not affiliated
with, endorsed by, sponsored by, or supported by NAVEE or its app vendor.
Product names identify compatible hardware only.

Download: https://github.com/JJRicks/volt/releases/latest
Start here: README.md
Install and pair: docs/getting-started.md
Using Volt: docs/user-guide.md
Supported features: FEATURES.txt
Build from source: docs/building.md

Requires Android 8.0+ with Bluetooth LE and a NAVEE scooter. Volt recognises
every NAVEE scooter by its Model ID and pictures it where a photo exists;
controls follow the official app's list for each model it lists; the two S2
Model IDs, newer than that list, get the lock and readings. The US UT5 MAX is
physically verified and a few other models are owner-tested (see FEATURES.txt).
First setup uses your working NAVEE account, or, for a scooter that isn't in the
NAVEE app, an owner key Volt makes; everyday Bluetooth use is local. Chrome +
USB is the recommended setup route. Computer ADB and on-phone Shizuku are also
available.
See the setup guide for requirements and validation limits.

Read PRIVACY.md for local storage, optional online maps and sensitive exports.
Keep owner setup files private and back up before clearing app data.
Volt is in English, plus Spanish, Portuguese (Portugal), Portuguese (Brazil),
Swedish, German, French, Italian, Dutch, Turkish and Polish (all beta, fully
translated); more languages are in progress.
CHANGELOG.md lists updates; SECURITY.md explains sensitive reporting.
